# Watir Cucumber Allure Framework

This wiki describes the Ruby 4 framework for browser automation with Cucumber,
Watir, Selenium WebDriver, and Allure Report.

## Start here

- [Architecture](Architecture.md) explains execution flow and responsibilities.
- [Running the suite](Running-the-suite.md) covers setup, commands, and outputs.
- [Security](Security.md) documents dependency and driver safeguards.
- [Troubleshooting](Troubleshooting.md) covers common Windows and browser issues.

The wiki sources are stored in `docs/wiki` so they are reviewed with the code.
After merge, copy these Markdown files to the repository's GitHub wiki if a
hosted wiki is desired.
